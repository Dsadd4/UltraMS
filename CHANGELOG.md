# Changelog

## 0.3.2.post1

- Package description updated; the code is unchanged from 0.3.2.

## 0.3.2

- Installable inference package with the Unsupervised, MoNA contrastive and UltraAtlas Search models; MGF input and optional mzML support.
- UltraMSdata pretraining with the prepared 160,641,162-spectrum GNPS/MassIVE corpus and its 21,586,258-spectrum ion-mode-balanced subset.
- PyTorch fine-tuning, batch embedding and spectral-search examples, plus a MassSpecGym contrastive tutorial using its released data folds.
- Benchmark code, measured results and metric recalculation for spectral properties and molecular identification.
- Public MSnLib benchmark partitions (Zenodo DOI 10.5281/zenodo.23963488) and the SpectraVerse dataset (Zenodo DOI 10.5281/zenodo.23964105) for downstream analyses.
- API/CLI reference, model-selection guidance, input-format documentation and researcher tutorials.
