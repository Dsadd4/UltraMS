Independent 30-epoch training and full MSnLib test of the four comparison readouts from public inputs. All runs use 446,667 training spectra, 55,980 validation spectra, 57,437 test spectra, and seed 0. `results.csv` summarizes the selected validation epoch and test Top-1/5/20 accuracy; each method directory contains its configuration, training history, validation metrics, and test metrics.

This run uses the newer `scaled_masked` DeepSets calculation. The manuscript result uses the original `reported` calculation and its [separate training record](../single_spectrum_deepsets_reported/). Both sets of selected weights are available in [UltraMS Benchmark Assets](https://huggingface.co/datasets/dsadd4/UltraMS-Benchmark-Assets/tree/main/molecular_identification/single_spectrum_readouts).
